# Code Of Conduct

This project expects respectful, evidence-based collaboration.

## Expected Behavior

- Be precise and constructive.
- Discuss tradeoffs in terms of behavior, code quality, and maintenance cost.
- Respect contributors with different backgrounds and experience levels.

## Unacceptable Behavior

- Harassment or personal attacks
- Discriminatory language or conduct
- Deliberate disruption or repeated bad-faith argument
- Sharing private information without consent

Maintainers may moderate discussions and contributions to protect the project environment.
